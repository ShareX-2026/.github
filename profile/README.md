ShareX is a free and open-source Windows application designed for **screenshots, screen recording, file sharing and productivity workflows**.

It can capture regions, windows, monitors, scrolling pages and full screens. Captures can then be edited, annotated, saved locally, copied to the clipboard or uploaded to a configured destination.

ShareX also includes screen recording, GIF recording, OCR, QR-code tools, color picking, image utilities and customizable hotkey-based workflows.

> **Important:** ShareX is a Windows application. Download it from the official ShareX website, official GitHub repository, Microsoft Store or another official distribution channel. Avoid unofficial "ShareX download" websites that repackage the application.

## Supported Capture Types

ShareX supports multiple ways to capture content from your Windows desktop:

* **Fullscreen capture**
* **Active window capture**
* **Active monitor capture**
* **Region capture**
* **Scrolling capture**
* **Last region capture**
* **Custom region capture**
* **Screen recording**
* **GIF recording**
* **Automatic capture**

After a capture, ShareX can automatically perform additional actions such as saving the file, copying it to the clipboard, opening the editor, uploading it, running another action or processing the result through a custom workflow.

## Screenshot Features

ShareX provides several screenshot modes for different situations.

### Region Capture

Select any area of the screen and capture it immediately.

Region capture can be used for:

* Bug reports
* Tutorials
* Documentation
* Support messages
* Game screenshots
* Software demonstrations
* Technical documentation

The capture editor provides tools for adding context before sharing the image.

### Window Capture

Capture an individual application window instead of selecting the area manually.

This is useful when documenting:

* Applications
* Dialog boxes
* Settings windows
* Browser windows
* Error messages

### Fullscreen Capture

Capture the entire desktop or selected monitor.

This is useful when documenting a complete desktop state or multi-window workflow.

### Scrolling Capture

Scrolling capture can combine a long webpage, document or application window into a single image.

This is particularly useful for:

* Long webpages
* Documentation
* Chat conversations
* Configuration pages
* Large application windows

## Troubleshooting

### Screenshot Hotkey Does Not Work

Check the following:

1. Make sure ShareX is running.
2. Verify that the hotkey is assigned in ShareX.
3. Check whether another application uses the same shortcut.
4. Try assigning a different hotkey.
5. Restart ShareX.
6. Restart Windows if the shortcut remains blocked.

### Capture Does Not Work Correctly

Try:

1. Restarting ShareX.
2. Testing fullscreen capture.
3. Testing region capture.
4. Disabling conflicting screen-overlay software.
5. Updating ShareX.
6. Testing the capture on another application.

### Scrolling Capture Fails

Scrolling capture can behave differently depending on the application being captured.

Try:

1. Using a different capture region.
2. Maximizing the target window.
3. Making sure the page is fully loaded.
4. Testing another application or browser.
5. Checking whether the target application uses custom rendering that interferes with scrolling capture.

### Screen Recording Does Not Start

Check:

1. ShareX is running correctly.
2. The selected recording method is available.
3. The recording region is valid.
4. Another application is not blocking screen capture.
5. The output location is writable.
6. Sufficient disk space is available.

### OCR Does Not Recognize Text

Try:

1. Capturing a higher-resolution region.
2. Selecting only the text area.
3. Increasing the image scale before OCR.
4. Checking the selected OCR language/settings.
5. Testing OCR on a clearer image.

OCR accuracy depends heavily on image quality, font rendering and the source language.

## System Requirements

ShareX is designed for Windows desktop systems.

Typical requirements include:

* **Operating System:** Windows
* **Architecture:** Modern 64-bit Windows systems
* **GPU:** Standard Windows-compatible graphics hardware
* **Storage:** Space for the application and captured files
* **Permissions:** Normal user permissions for standard operation
* **Internet:** Optional for downloading updates and uploading files

Actual requirements depend on the capture mode, recording settings, resolution and external tools being used.

For example, high-resolution video recording requires considerably more storage and processing resources than ordinary screenshots.

## ShareX and Games

ShareX can be useful for capturing games, applications and desktop environments.

For game screenshots:

1. Start ShareX.
2. Launch the game.
3. Configure a suitable capture hotkey.
4. Capture the desired region, window or screen.

If a particular game does not capture correctly, try borderless/windowed mode or another ShareX capture method.
